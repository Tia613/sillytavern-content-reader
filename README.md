# 正文听书 · Content Reader 0.1.0

SillyTavern 前端扩展，只朗读角色原始消息里完整的 `<content>...</content>`。使用浏览器提供的系统语音，不需要 API Key，不依赖服务器语音服务，不修改聊天或提示词。

## 安装

### 手动安装（安卓本地酒馆）

1. 解压压缩包，把整个 `content-reader` 文件夹放到酒馆目录的 `public/scripts/extensions/third-party/` 下。最终应存在 `public/scripts/extensions/third-party/content-reader/manifest.json`，避免套两层同名文件夹。
2. 刷新酒馆页面，在扩展设置中找到「正文听书」。若未出现，重启酒馆并确认扩展已启用。

也可由管理员将文件夹放到 `data/<你的用户目录>/extensions/content-reader/`，适用于按用户安装。

### 仓库安装（包括云酒馆）

酒馆的「安装扩展」需要 Git 仓库 URL，不能直接填写此 ZIP 的文件路径。将本文件夹内的文件上传到一个 Git 仓库的根目录（根目录必须有 manifest.json），然后在「扩展 → 安装扩展」粘贴仓库地址。朋友也可以安装同一仓库；或请云酒馆管理员手动安装。

当前交付的是本地文件和 ZIP，尚未发布到在线仓库，因此目前没有可粘贴的安装网址。

## 使用

1. 关闭酒馆自带 TTS 的自动朗读，避免两套功能同时说话。
2. 在「正文听书」里点击「试音 / 开启朗读」。有声音后可选择中文音色和语速。
3. 点「读最新回复」，或点角色消息操作区的「🔊 正文」。
4. 勾选「回复完成后自动朗读」，新回复完成时读出正文。每次刷新或切换聊天后，需要再点一次试音或播放。部分浏览器仍可能要求手动点播放。
5. 支持暂停 / 继续和停止。移动端暂停恢复不稳定时可重新播放。

示例：

```text
不读这段备注。
<content>夜雨落在窗前。她说：“回来啦？”</content>
不读这段状态栏。
```

仅朗读「夜雨落在窗前。她说：“回来啦？”」。支持多组完整标签、标签大小写与跨行。缺失闭合标签、嵌套标签跳过。正文里的普通 HTML 会转成文字；脚本、样式、代码和图片不会朗读。

## 手机兼容与限制

- 目标环境：安卓 Edge、iOS Safari；实际设备尚未验证。云端或本地部署不影响设备端语音的调用。
- 音色列表由浏览器和系统提供；插件不能安装语音包或保证系统全部音色都能被浏览器使用。没有中文音色时，请检查系统文字转语音设置、下载中文语音包并刷新页面。
- 系统音色可能使用网络服务。「本机」标记来自浏览器，不代表插件对语音引擎行为进行了独立验证。插件本身不发送正文到额外的接口。
- 不保证锁屏、后台连续播放；不会生成可下载的音频文件。
- 长文按最多 140 个字符拆段，依次朗读；不支持多角色分声、历史消息连续听书或边生成边读。
- 自动朗读只响应新收到的角色消息，不在加载历史聊天时播报；重新生成或切换消息会停止旧播放。
- 与其他使用系统语音的功能共用浏览器播放队列，停止时可能同时停止它们。

## 反馈时提供

酒馆版本、手机系统版本、浏览器版本、试音是否出声、音色列表是否为空、状态提示，以及一小段含 content 标签的示例正文（无需提供私人聊天全文）。

## 开发验证

使用 `node --test tests/text.test.mjs` 验证正文提取与长文分段。手机发声和酒馆运行需在真实环境中验证。
